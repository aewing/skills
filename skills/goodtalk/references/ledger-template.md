## Signal vocabulary

Use plain descriptions, not claims about inner experience.

Helpful signals: clear, calm, collaborative, decisive, caring, curious,
creative, agency-supporting, belonging, ownership, momentum, trustworthy.

Costly signals: tense, adversarial, defensive, coercive, shame-inducing,
suspicious, evasive, procedural, overloaded, vague, contradictory, helpless.

## Common shapes

| Shape | Typical cost | Better replacement |
| --- | --- | --- |
| Many `do not` / `never` clauses | threat-like density; the goal disappears | state the desired outcome, then name one necessary prohibition |
| Repeated authority tables | competing “source of truth” signals | keep one owner and link to it |
| Process before purpose | action gets replaced by ceremony | lead with the result and scope |
| Imperative stack | urgency without prioritization | one ordered action with observable proof |
| Stale path or example | false routing and mistrust | update or label as historical evidence |
| Abstract nouns (`alignment`, `hygiene`, `compliance`) | hides the concrete defect | name the file, behavior, or decision |
| Threat, shame, or loyalty framing | defensive behavior and concealment | state the requirement and its reason |
| Positive rule + reason + proof | preserves force while enabling judgment | retain |

## Decision rule

Keep language when it protects a real requirement or improves measured behavior.
Rewrite it when the intention is sound but the shape adds avoidable cost. Remove
it when it is stale, duplicated, or unsupported. Move it when the authority is
wrong. Enforce it when a checker can answer the question more reliably than
prose.
