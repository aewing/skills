# Goodtalk research — 2026-08-15

Scope: how portable agent skills are specified, described, and structured, to
ground the skills repo's own writing profile.

## Sources

- anthropics/skills — `skills/skill-creator/SKILL.md` (retrieved 2026-08-15,
  https://github.com/anthropics/skills)
- anthropics/skills — `spec/agent-skills-spec.md` (retrieved 2026-08-15)
- agentskills.io (landing page, retrieved 2026-08-15)

## Adopted findings

1. The skill description is the primary triggering mechanism. "When to use"
   information belongs in the description; descriptions should be a little
   pushy to counter undertriggering. → grounds `skill.triggering-description`.
2. SKILL.md under ~500 lines; references live one hop away in `references/`
   (or `examples/`), loaded on demand. → grounds `skill.progressive-disclosure`.
3. Bundle shape: `skill-name/SKILL.md` + optional `references/`, `scripts/`,
   `assets/`. → repo already follows this shape.
4. Description limit: 1024 chars per the Agent Skills spec.

## Candidates not adopted

- Adding formal eval harnesses per skill (anthropic skill-creator suggests
  evals + variance analysis): valuable eventually, out of scope for this pass.
  Tracked as a future improvement, not a rule.

## Impact on this repo

- Add a concrete starter profile so goodtalk's `standards init` has a visible
  artifact shape (`skills/goodtalk/examples/standards.json.starter`).
- Sharpen trigger quality in descriptions and add when-not sections where the
  loops already model them.
